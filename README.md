Cart Based Ordering System

This is a simple food ordering application made using Python and Tkinter. The project allows users to select food items from a menu, add them to a cart, and view the total bill in real time.

Built With

Python and Tkinter

How to Run

Run the file using Python:
python app.py

Features

You can add items to the cart by clicking buttons
Quantities increase if the same item is selected again
The total price is calculated automatically
You can clear the cart anytime

Purpose

This project was made for learning basic GUI development in Python and understanding how cart systems work.
